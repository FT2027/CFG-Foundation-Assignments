# CFG-Foundation-Assignments

## Travel Log Application

### Project description 
Welcome to the **Travel Log App**! Whether you are a seasoned traveller or just getting started, this app gives all your adventures, past and future, a home. Log the countries and cities you have explored and the dates you were there, then look back to relive your favourite memories or start planning your next escape. 

---

### User Stories 
1. **As a** Frequent traveler, **I want to** I want to log a new trip with details like country, city, and dates visited, **so that** I can keep an organized history of all my travels.
2. **As a** travel enthusiast, **I want to** view a list of all the countries and cities I have visited, **so that** I can easily see my travel progress over time. 
3. **As a** user, **I want to** filter or search my log by country or year or month, **so that** I can find specific memories from previous trips quickly.
4. **As a** trip planner, **I want to** delete or edit an existing travel entry, **so that** I can keep my travel log accurate and up to date.
